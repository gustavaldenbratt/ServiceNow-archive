# ServiceNow Task Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a read-only ServiceNow task-table archive: a connection setting, a dynamic table picker (any table extending `task`), a queued incremental sync (records + journal + attachments), and a browse/detail UI.

**Architecture:** A `ServiceNowClient` HTTP wrapper talks to the ServiceNow Table/Attachment REST APIs. A `TaskTableResolver` walks `sys_db_object` to discover task-descendant tables. A `RecordSyncService`, run inside a queued `SyncTableJob`, pages through records per configured table, upserting into a generic JSON store (`sn_records`, `sn_journal_entries`, `sn_attachments`) and advancing a per-table cursor (`sn_table_configs.last_synced_cursor`) only after each page fully succeeds. Inertia/React pages under `resources/js/pages/servicenow/` expose connection settings, table configuration, run history, and record browsing/detail, sharing a new `ServiceNowLayout` (mirroring the existing `settings/layout.tsx` pattern).

**Tech Stack:** Laravel 13 (PHP 8.4), Eloquent + SQLite, Laravel queues (database driver), Laravel filesystem (local disk), Inertia v3 + React 19, Laravel Wayfinder, Pest 4.

---

## Reference conventions (confirmed in this codebase before writing this plan)

- Controllers use constructor-promoted dependencies, explicit return types, FormRequest classes per action group (see `app/Http/Controllers/Settings/ProfileController.php`, `app/Http/Requests/Settings/ProfileUpdateRequest.php`).
- Inertia pages use the `<Form {...Controller.method.form()}>` render-prop pattern exclusively (see `resources/js/pages/settings/profile.tsx`, `resources/js/components/delete-user.tsx`). No raw `router.post()` calls are used anywhere in `resources/js/pages`.
- Wayfinder generates `resources/js/routes/<dot.path>` from route names and `resources/js/actions/App/Http/Controllers/<Namespace>/<Controller>` from controllers. These are regenerated by `php artisan wayfinder:generate` or automatically by the Vite plugin in dev/build. **Every task below that adds a route/controller must be followed by running `php artisan wayfinder:generate` before the matching frontend task.**
- Page-level layout selection happens centrally in `resources/js/app.tsx`'s `layout: (name) => ...` switch; each page additionally sets a static `Page.layout = { breadcrumbs: [...] }` for breadcrumb data consumed by the layout.
- Models use the `#[Fillable([...])]` attribute (PHP 8.4 attribute), a `casts(): array` method, and `HasFactory` where a factory exists (see `app/Models/User.php`).
- Tests are Pest, all under `tests/Feature/**`, extending `Tests\TestCase` with `RefreshDatabase` (configured globally in `tests/Pest.php`); there is no Laravel-bootstrapped `tests/Unit` here, so all new tests go in `tests/Feature/ServiceNow/`.
- Run tests with `php artisan test --compact --filter=<Name>`. Run `vendor/bin/pint --dirty --format agent` after any PHP changes, before considering a task done.

### Task 3: ServiceNowClient HTTP wrapper

**Files:**
- Create: `app/Services/ServiceNow/ServiceNowClient.php`
- Test: `tests/Feature/ServiceNow/ServiceNowClientTest.php`

This wraps the ServiceNow Table API and Attachment API: basic auth, pagination, and the specific query syntax ServiceNow expects (`sysparm_query`, `sysparm_display_value=all`, etc.). All other services depend on this and only this for I/O — keeping ServiceNow's HTTP quirks isolated here is what lets `RecordSyncService` be tested without faking the queue or hitting a real instance.

- [x] **Step 1: Write the failing test**

```php
<?php

use App\Services\ServiceNow\ServiceNowClient;
use Illuminate\Support\Carbon;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Sleep;

function makeClient(): ServiceNowClient
{
    return new ServiceNowClient('https://dev1234.service-now.com', 'svc-account', 'secret');
}

test('test connection returns true on a successful response', function () {
    Http::fake([
        'dev1234.service-now.com/api/now/table/sys_db_object*' => Http::response(['result' => []]),
    ]);

    expect(makeClient()->testConnection())->toBeTrue();
});

test('test connection returns false on a failed response', function () {
    Sleep::fake();

    Http::fake([
        'dev1234.service-now.com/api/now/table/sys_db_object*' => Http::response(['error' => 'unauthorized'], 401),
    ]);

    expect(makeClient()->testConnection())->toBeFalse();
});

test('fetch table hierarchy paginates until a short page is returned', function () {
    Http::fake([
        'dev1234.service-now.com/api/now/table/sys_db_object*' => Http::sequence()
            ->push(['result' => array_fill(0, 200, ['name' => 'x', 'sys_id' => '1', 'super_class' => null])])
            ->push(['result' => [['name' => 'task', 'sys_id' => 'task-id', 'super_class' => null]]]),
    ]);

    $rows = makeClient()->fetchTableHierarchy();

    expect($rows)->toHaveCount(201);
    expect($rows[200])->toBe(['name' => 'task', 'sys_id' => 'task-id', 'super_class' => null]);
});

test('fetch table hierarchy unwraps a reference-style super_class', function () {
    Http::fake([
        'dev1234.service-now.com/api/now/table/sys_db_object*' => Http::response([
            'result' => [
                ['name' => 'incident', 'sys_id' => 'inc-id', 'super_class' => ['value' => 'task-id']],
            ],
        ]),
    ]);

    $rows = makeClient()->fetchTableHierarchy();

    expect($rows[0]['super_class'])->toBe('task-id');
});

test('fetch records sends a since filter and pagination params', function () {
    Http::fake([
        'dev1234.service-now.com/api/now/table/incident*' => Http::response(['result' => [['sys_id' => ['value' => 'a']]]]),
    ]);

    $result = makeClient()->fetchRecords('incident', Carbon::parse('2026-01-01 00:00:00'), 50, 200);

    expect($result)->toHaveCount(1);

    Http::assertSent(function ($request) {
        return $request->url() === 'https://dev1234.service-now.com/api/now/table/incident?'.
            'sysparm_query=sys_updated_on%3E%3D2026-01-01+00%3A00%3A00%5EORDERBYsys_updated_on&'.
            'sysparm_display_value=all&sysparm_exclude_reference_link=true&sysparm_offset=50&sysparm_limit=200';
    });
```

```php
     */

        $offset = 0;

            $page = $this->request()->get('table/sys_db_object', [
                'sysparm_fields' => 'name,sys_id,super_class',
                'sysparm_limit' => self::HIERARCHY_PAGE_SIZE,
                'sysparm_offset' => $offset,

            : 'ORDERBYsys_updated_on';

        return $this->request()->get("table/{$table}", [
            'sysparm_query' => $query,
            'sysparm_display_value' => 'all',
            'sysparm_exclude_reference_link' => 'true',
            'sysparm_offset' => $offset,
            'sysparm_limit' => $limit,
        ])->throw()->json('result') ?? [];
    }

    /**
     * @param  array<int, string>  $sysIds
     * @return array<int, array<string, mixed>>
     */
    public function fetchJournalEntries(string $table, array $sysIds): array
    {
        if ($sysIds === []) {
            return [];
        }

        $query = 'element_idIN'.implode(',', $sysIds).'^elementINcomments,work_notes^ORDERBYsys_created_on';

        return $this->request()->get('table/sys_journal_field', [

            'sysparm_exclude_reference_link' => 'true',
            'sysparm_limit' => 1000,

            return [];
        }

        $query = "table_name={$table}^table_sys_idIN".implode(',', $sysIds);

        return $this->request()->get('attachment', [
            'sysparm_query' => $query,
            'sysparm_limit' => 1000,
        ])->throw()->json('result') ?? [];

    {
        return $this->request()
            ->get("attachment/{$attachmentSysId}/file")
            ->throw()
            ->body();

            ->acceptJson()
            ->retry(3, fn (int $attempt) => 100 * (2 ** $attempt));
```

```php
<?php

namespace App\Services\ServiceNow;

class TaskTableResolver
{
    public function __construct(private readonly ServiceNowClient $client) {}

    /**
     * @return array<int, string> table names descending from $rootTable, excluding $rootTable itself, sorted alphabetically
     */
    public function resolveDescendantsOf(string $rootTable = 'task'): array
    {
        $rows = $this->client->fetchTableHierarchy();

        $byName = [];
        $bySysId = [];

        foreach ($rows as $row) {
            $byName[$row['name']] = $row;
            $bySysId[$row['sys_id']] = $row;
        }

        if (! isset($byName[$rootTable])) {
            return [];
        }

        $rootSysId = $byName[$rootTable]['sys_id'];

        $descendants = [];

        foreach ($byName as $name => $row) {
            if ($name !== $rootTable && $this->descendsFrom($row, $bySysId, $rootSysId)) {
                $descendants[] = $name;
            }
        }

        sort($descendants);

        return $descendants;
    }

    /**
     * @param  array{name: string, sys_id: string, super_class: ?string}  $row
     * @param  array<string, array{name: string, sys_id: string, super_class: ?string}>  $bySysId
     */
    private function descendsFrom(array $row, array $bySysId, string $rootSysId): bool
    {
        $current = $row;
        $visited = [];

        while ($current['super_class'] !== null) {
            if (isset($visited[$current['sys_id']])) {
                return false;
            }

            $visited[$current['sys_id']] = true;

            if ($current['super_class'] === $rootSysId) {
                return true;
            }

            $current = $bySysId[$current['super_class']] ?? null;

            if ($current === null) {
                return false;
            }
        }

        return false;
    }
}
```

```php
<?php

namespace App\Services\ServiceNow;

use App\Models\SnAttachment;
use App\Models\SnJournalEntry;
use App\Models\SnRecord;
use App\Models\SnTableConfig;
use App\Models\SyncRun;
use Illuminate\Support\Facades\Storage;
use Throwable;

class RecordSyncService
{
    private const PAGE_SIZE = 200;

    public function __construct(private readonly ServiceNowClient $client) {}

    public function sync(SnTableConfig $config, SyncRun $run): void
    {
        $since = $config->last_synced_cursor ?? $config->fetch_since;
        $offset = 0;

        while (true) {
            $page = $this->client->fetchRecords($config->table_name, $since, $offset, self::PAGE_SIZE);

            if ($page === []) {
                break;
            }

            $sysIds = [];
            $maxUpdatedAt = null;

            foreach ($page as $raw) {
                $record = $this->upsertRecord($config->table_name, $raw);
                $sysIds[] = $record->sys_id;

                if ($record->sys_updated_at !== null && (! $maxUpdatedAt || $record->sys_updated_at->gt($maxUpdatedAt))) {
                    $maxUpdatedAt = $record->sys_updated_at;
                }
            }

            $this->syncJournalEntries($config->table_name, $sysIds);
            $this->syncAttachments($config->table_name, $sysIds);

            $run->increment('records_processed', count($page));

            if ($maxUpdatedAt !== null) {
                $config->update(['last_synced_cursor' => $maxUpdatedAt]);
            }

            if (count($page) < self::PAGE_SIZE) {
                break;
            }

            $offset += self::PAGE_SIZE;
        }
    }

    private function upsertRecord(string $table, array $raw): SnRecord
    {
        return SnRecord::query()->updateOrCreate(
            [
                'table_name' => $table,
                'sys_id' => $this->extractValue($raw, 'sys_id'),
            ],
            [
                'number' => $this->extractValue($raw, 'number'),
                'sys_created_at' => $this->extractValue($raw, 'sys_created_on'),
                'sys_updated_at' => $this->extractValue($raw, 'sys_updated_on'),
                'state' => $this->extractDisplayValue($raw, 'state'),
                'short_description' => $this->extractValue($raw, 'short_description'),
                'assigned_to' => $this->extractDisplayValue($raw, 'assigned_to'),
                'data' => $raw,
            ],
        );
    }

    /**
     * @param  array<int, string>  $sysIds
     */
    private function syncJournalEntries(string $table, array $sysIds): void
    {
        if ($sysIds === []) {
            return;
        }

        foreach ($this->client->fetchJournalEntries($table, $sysIds) as $raw) {
            SnJournalEntry::query()->updateOrCreate(
                ['sys_id' => $this->extractValue($raw, 'sys_id')],
                [
                    'record_sys_id' => $this->extractValue($raw, 'element_id'),
                    'table_name' => $table,
                    'element' => $this->extractValue($raw, 'element'),
                    'value' => $this->extractValue($raw, 'value'),
                    'sys_created_by' => $this->extractValue($raw, 'sys_created_by'),
                    'sys_created_at' => $this->extractValue($raw, 'sys_created_on'),
                ],
            );
        }
    }

    /**
     * @param  array<int, string>  $sysIds
     */
    private function syncAttachments(string $table, array $sysIds): void
    {
        if ($sysIds === []) {
            return;
        }

        foreach ($this->client->fetchAttachmentsMeta($table, $sysIds) as $raw) {
            $attachmentSysId = $this->extractValue($raw, 'sys_id');

            if ($attachmentSysId === null || SnAttachment::query()->where('sys_id', $attachmentSysId)->exists()) {
                continue;
            }

            $recordSysId = $this->extractValue($raw, 'table_sys_id');
            $fileName = $this->extractValue($raw, 'file_name') ?? $attachmentSysId;
            $storagePath = "sn-attachments/{$table}/{$recordSysId}/{$attachmentSysId}-{$fileName}";

            try {
                $contents = $this->client->downloadAttachment($attachmentSysId);
            } catch (Throwable $e) {
                report($e);

                continue;
            }

            Storage::disk('local')->put($storagePath, $contents);

            SnAttachment::query()->create([
                'sys_id' => $attachmentSysId,
                'record_sys_id' => $recordSysId,
                'table_name' => $table,
                'file_name' => $fileName,
                'content_type' => $this->extractValue($raw, 'content_type'),
                'size_bytes' => (int) $this->extractValue($raw, 'size_bytes'),
                'storage_path' => $storagePath,
            ]);
        }
    }

    private function extractValue(array $raw, string $field): ?string
    {
        $entry = $raw[$field] ?? null;

        if (is_array($entry)) {
            return $entry['value'] ?? null;
        }

        return $entry;
    }

    private function extractDisplayValue(array $raw, string $field): ?string
    {
        $entry = $raw[$field] ?? null;

        if (is_array($entry)) {
            return $entry['display_value'] ?? ($entry['value'] ?? null);
        }

        return $entry;
    }
}
```

```php
<?php

namespace App\Jobs;

use App\Models\SnTableConfig;
use App\Models\SyncRun;
use App\Services\ServiceNow\RecordSyncService;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;
use Throwable;

class SyncTableJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(public int $tableConfigId) {}

    public function handle(RecordSyncService $service): void
    {
        $config = SnTableConfig::query()->findOrFail($this->tableConfigId);

        $run = SyncRun::query()->create([
            'table_name' => $config->table_name,
            'status' => 'running',
            'started_at' => now(),
        ]);

        try {
            $service->sync($config, $run);

            $run->update(['status' => 'success', 'finished_at' => now()]);
            $config->update(['last_run_status' => 'success']);
        } catch (Throwable $e) {
            $run->update(['status' => 'failed', 'error' => $e->getMessage(), 'finished_at' => now()]);
            $config->update(['last_run_status' => 'failed']);

            throw $e;
        }
    }
}
```

```php
<?php

namespace App\Http\Controllers\ServiceNow;

use App\Http\Controllers\Controller;
use App\Http\Requests\ServiceNow\ConnectionUpdateRequest;
use App\Models\SnConnection;
use App\Services\ServiceNow\ServiceNowClient;
use Illuminate\Http\RedirectResponse;
use Inertia\Inertia;
use Inertia\Response;

class ConnectionController extends Controller
{
    public function edit(): Response
    {
        $connection = SnConnection::current();

        return Inertia::render('servicenow/connection', [
            'connection' => [
                'instance_url' => $connection->instance_url,
                'username' => $connection->username,
                'has_password' => $connection->password !== null,
            ],
        ]);
    }

    public function update(ConnectionUpdateRequest $request): RedirectResponse
    {
        $connection = SnConnection::query()->first() ?? new SnConnection;

        $data = $request->validated();

        if (empty($data['password'])) {
            unset($data['password']);
        }

        $connection->fill($data);
        $connection->save();

        Inertia::flash('toast', ['type' => 'success', 'message' => __('Connection settings saved.')]);

        return to_route('servicenow.connection.edit');
    }

    public function test(): RedirectResponse
    {
        $connection = SnConnection::current();

        if (! $connection->instance_url) {
            Inertia::flash('toast', ['type' => 'error', 'message' => __('Configure the connection before testing it.')]);

            return to_route('servicenow.connection.edit');
        }

        $client = new ServiceNowClient($connection->instance_url, (string) $connection->username, (string) $connection->password);

        $successful = $client->testConnection();

        Inertia::flash('toast', [
            'type' => $successful ? 'success' : 'error',
            'message' => $successful
                ? __('Connection successful.')
                : __('Could not connect to ServiceNow with these credentials.'),
        ]);

        return to_route('servicenow.connection.edit');
    }
}
```

```php
namespace App\Http\Controllers\ServiceNow;

use App\Http\Controllers\Controller;
use App\Http\Requests\ServiceNow\TableConfigStoreRequest;
use App\Http\Requests\ServiceNow\TableConfigUpdateRequest;
use App\Jobs\SyncTableJob;
use App\Models\SnConnection;

use App\Services\ServiceNow\ServiceNowClient;
use App\Services\ServiceNow\TaskTableResolver;
use Illuminate\Http\RedirectResponse;
use Inertia\Inertia;
use Inertia\Response;
use Throwable;

class TableConfigController extends Controller
{
    public function index(): Response
    {
        $configs = SnTableConfig::query()->orderBy('table_name')->get();

        return Inertia::render('servicenow/tables', [
            'configs' => $configs,
            'availableTables' => $this->discoverAvailableTables($configs->pluck('table_name')->all()),
        ]);
    }

    public function store(TableConfigStoreRequest $request): RedirectResponse
    {
        SnTableConfig::query()->create($request->validated());

        Inertia::flash('toast', ['type' => 'success', 'message' => __('Table added.')]);

        return to_route('servicenow.tables.index');
    }

    public function update(TableConfigUpdateRequest $request, SnTableConfig $tableConfig): RedirectResponse
    {
        $tableConfig->update($request->validated());

        Inertia::flash('toast', ['type' => 'success', 'message' => __('Table updated.')]);

        return to_route('servicenow.tables.index');
    }

    public function sync(SnTableConfig $tableConfig): RedirectResponse
    {
        SyncTableJob::dispatch($tableConfig->id);

        Inertia::flash('toast', ['type' => 'success', 'message' => __('Sync started.')]);

        return to_route('servicenow.tables.index');
    }

    /**
     * @param  array<int, string>  $configuredTables
     * @return array<int, string>
     */
    private function discoverAvailableTables(array $configuredTables): array
    {
        $connection = SnConnection::current();

        if (! $connection->instance_url) {
            return [];
        }

        try {
            $client = new ServiceNowClient($connection->instance_url, (string) $connection->username, (string) $connection->password);
            $resolver = new TaskTableResolver($client);

            return array_values(array_diff($resolver->resolveDescendantsOf('task'), $configuredTables));
        } catch (Throwable) {
            return [];
        }
    }
}
```

```php
namespace App\Http\Controllers\ServiceNow;

use App\Http\Controllers\Controller;
```

```php
use Illuminate\Http\Request;
use Inertia\Inertia;

class RecordController extends Controller
{
    public function index(Request $request): Response
    {
        $filters = $request->validate([
            'table_name' => ['nullable', 'string'],
            'number' => ['nullable', 'string'],
            'state' => ['nullable', 'string'],
            'from' => ['nullable', 'date'],
            'to' => ['nullable', 'date'],
        ]);

        $records = SnRecord::query()
            ->when($filters['table_name'] ?? null, fn ($query, $value) => $query->where('table_name', $value))
            ->when($filters['number'] ?? null, fn ($query, $value) => $query->where('number', 'like', "%{$value}%"))
            ->when($filters['state'] ?? null, fn ($query, $value) => $query->where('state', $value))
            ->when($filters['from'] ?? null, fn ($query, $value) => $query->where('sys_updated_at', '>=', $value))
            ->when($filters['to'] ?? null, fn ($query, $value) => $query->where('sys_updated_at', '<=', $value))
            ->orderByDesc('sys_updated_at')
            ->paginate(25)
            ->withQueryString();

        return Inertia::render('servicenow/records/index', [
            'records' => $records,
            'filters' => $filters,
            'tableNames' => SnTableConfig::query()->orderBy('table_name')->pluck('table_name'),
        ]);
    }

    public function show(SnRecord $record): Response
    {
        return Inertia::render('servicenow/records/show', [
            'record' => $record,
            'journalEntries' => $record->journalEntries()->get(),
            'attachments' => $record->attachments()->get(),
        ]);
    }
}
```

```tsx
import { Head } from '@inertiajs/react';

import { Badge } from '@/components/ui/badge';

type FieldValue = { value: string | null; display_value?: string | null } | string | null;

type Record = {
    id: number;
    table_name: string;
    number: string | null;
    sys_updated_at: string | null;
    data: Record<string, FieldValue> | unknown;
};

type JournalEntry = {
    id: number;
    element: string;
    value: string | null;
    sys_created_by: string | null;
    sys_created_at: string | null;
};

type Attachment = {
    id: number;
    file_name: string;
    content_type: string | null;
};

function fieldLabel(field: FieldValue): string {
    if (field === null) {
        return '—';
    }

    if (typeof field === 'string') {
        return field;
    }

    return field.display_value ?? field.value ?? '—';
}

export default function RecordShow({
    record,
    journalEntries,
    attachments,
}: {
    record: Record;
    journalEntries: JournalEntry[];
    attachments: Attachment[];
}) {
    const fields = Object.entries((record.data ?? {}) as Record<string, FieldValue>);

    return (
        <>
            <Head title={record.number ?? `Record #${record.id}`} />

            <div className="space-y-8">
                <div className="flex items-center gap-3">
                    <Heading
                        variant="small"
                        title={record.number ?? `Record #${record.id}`}
                    />
                    <Badge variant="outline">{record.table_name}</Badge>
                </div>

                <div className="space-y-2">
                    <Heading variant="small" title="Fields" />
                    <dl className="grid grid-cols-1 gap-3 md:grid-cols-2">
                        {fields.map(([field, value]) => (
                            <div key={field} className="space-y-0.5">
                                <dt className="text-xs font-medium text-muted-foreground">{field}</dt>
                                <dd className="text-sm">{fieldLabel(value)}</dd>
                            </div>
                        ))}
                    </dl>
                </div>

                <div className="space-y-2">
                    <Heading variant="small" title="Journal" />
                    {journalEntries.length === 0 && (
                        <p className="text-sm text-muted-foreground">No comments or work notes.</p>
                    )}
                    <div className="space-y-3">
                        {journalEntries.map((entry) => (
                            <div key={entry.id} className="rounded-lg border p-3">
                                <div className="flex items-center gap-2 text-xs text-muted-foreground">
                                    <Badge variant="outline">{entry.element}</Badge>
                                    <span>{entry.sys_created_by}</span>
                                    <span>{entry.sys_created_at}</span>
                                </div>
                                <p className="mt-1 text-sm whitespace-pre-wrap">{entry.value}</p>
                            </div>
                        ))}
                    </div>
                </div>

                <div className="space-y-2">
                    <Heading variant="small" title="Attachments" />
                    {attachments.length === 0 && (
                        <p className="text-sm text-muted-foreground">No attachments.</p>
                    )}
                    <div className="flex flex-wrap gap-4">
                        {attachments.map((attachment) =>
                            attachment.content_type?.startsWith('image/') ? (
                                <a
                                    key={attachment.id}
                                    href={showAttachment(attachment.id).url}
                                    target="_blank"

                                >
                                    {attachment.file_name}
                                </a>
                            ),
                        )}
                    </div>
                </div>
            </div>
        </>
    );
}
```
